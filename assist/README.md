# 台北通「陪你辦」協辦功能 MVP

不是代填，是陪填。協助者（里長、家人、1999 客服）在自己的裝置上帶著長輩走每一步，
所有個資的授權與最後送出，只發生在長輩本人已實名登入的台北通手機上。

提案與設計決策見 [docs/協辦功能提案.md](docs/協辦功能提案.md)。

## 專案結構

| 資料夾 | 內容 |
|---|---|
| `assist/assist_backend/` | Node.js 後端：Express REST API + Socket.IO 即時推播 |
| `assist/assist_web/` | Flutter Web 前端：協助者工作台（電腦版）與長輩手機模擬 |
| repo 根目錄 | 台北通 App，長輩端功能在 `lib/page/assist/` |

## 啟動

```bash
cd assist/assist_backend && npm install && npm start
```

開啟 http://localhost:3000，可選：

- `/#/demo` 並排示範：左邊協助者工作台，右邊長輩手機，適合評審展示
- `/#/helper` 協助者工作台（電腦版）
- `/#/elder` 長輩的手機，可在另一台裝置用同一個區網網址開啟

前端修改後要重新編譯，後端會直接提供 `assist/assist_web/build/web`：

```bash
cd assist/assist_web && fvm flutter build web --release --no-web-resources-cdn
```

路徑含中文時 `flutter analyze` 會讓 Dart 分析伺服器當掉，請從純英文路徑的符號連結執行。

## 台北通 App（長輩端）

長輩端已直接接進這個 repo 的台北通 App。工作人員端仍使用網頁版協助者工作台。

```bash
fvm flutter run   # 在 repo 根目錄執行
```

- **首頁徽章**：有人送出協助請求時，首頁最上方出現持續性徽章並倒數，沒有關閉鈕，回應或逾時才會消失。同時會發一則系統通知。
- **入口**：首頁 1999 下方的「不會用嗎？請人陪我辦」產生配對碼。「我的帳戶 › 歷程與授權管理」可查協辦紀錄。
- **連線**：模擬器直接連 `http://localhost:3000`。實機請加上 `--dart-define=ASSIST_API=http://<電腦區網 IP>:3000`。
- **動態字型**：所有協辦頁面跟著 iOS 字型大小縮放，放大上限為 AX3 倍率。大字時，主要按鈕會移到不用捲動就看得到的位置。
- **模擬帳號**：App 的模擬帳號已改為王大明，對應後端的長輩資料。

新增的程式碼集中在 `lib/page/assist/`、`lib/service/assist_service.dart` 與 `lib/bean/assist.dart`。原有檔案只改了路由、首頁、帳戶頁的入口與啟動時註冊服務。

## 後端測試

```bash
cd assist/assist_backend && npm test
```

15 項測試涵蓋完整流程、台北通帳號登入與每一條安全規則。

## 已實作的安全機制

- **協助者看不到個資**：協助者端所有資料都經過同一個視圖函式輸出，敏感欄位只有狀態沒有值。測試會掃描協助者收到的所有 API 回應與推播，確認沒有任何長輩個資。
- **逐項授權**：每一項個資獨立詢問，同一時間只能有一個授權請求，同一欄位最多問 3 次。
- **只有長輩能送出**：送出、授權都只接受長輩身分的 token。
- **防列舉**：以姓名、生日、身分證末四碼查找時，找得到與找不到的回應完全相同，對不上的請求變成不會送達的「幽靈請求」並照常逾時。每 10 分鐘最多查 5 次。長輩可在自己的紀錄看到「有人用您的資料查找您」。
- **配對碼**：6 位數、2 分鐘有效、只能用一次，重新產生後舊碼失效，輸入次數有上限。
- **防騷擾**：長輩可一鍵封鎖並回報。同一協助者被拒絕 3 次後自動封鎖。
- **隨時結束與逾時**：長輩按結束後協助者立即失效。閒置 30 分鐘自動結束。結束或送出後清除 session 中的個資。
- **不可竄改的稽核紀錄**：每個動作寫入雜湊鏈，任何一筆被改都會被偵測到。紀錄只寫「發生什麼」，不寫個資的值。
