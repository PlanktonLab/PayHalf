# 承辦人表單後台(示意版)

> 已整合進承辦工作台的「我的表單」(`assist/assist_web`,網址 `/#/forms`),與陪辦共用同一套介面。
> 這個單檔版本保留作為原型對照,後端提供在 `/admin/legacy/`。

給各局處行政人員建立「民眾要填寫的表單」的電腦網頁,單一 HTML 檔,直接用瀏覽器開啟 `index.html` 即可,不需要安裝或建置。

- 單頁編輯(類 Google 表單):問題／回覆／設定三個分頁,點選題目就地編輯
- 手機預覽、復原與重做、長輩好懂檢查、允許協助辦理、回覆資料與 CSV 匯出
- 資料暫存在瀏覽器 localStorage,回覆為示意假資料;尚未串接後端
- 配色取自本專案 `lib/util/tp_colors.dart`
- 圖示來自 [Lucide](https://lucide.dev)(ISC 授權)
- 後端介面草案見 [API需求.md](API需求.md)
