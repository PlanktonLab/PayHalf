# 雙手機展示動線

故事:**看護(印尼籍)用印尼文,幫不識字的長輩辦重陽敬老禮金;長輩用中文,只要確認。**
左邊手機是看護,右邊手機是長輩。這是整個作品最有感的一刻:看護一按,長輩手機立刻跳出邀請。

## 展示前準備(5 分鐘)
1. **啟動共用模擬後端**(在 `services/` 目錄):
   ```bash
   node mock-server/server.mjs
   ```
2. **啟動微服務,指定用共用後端**:
   ```bash
   # PowerShell
   $env:VITE_ASSIST_API_BASE = 'auto'; pnpm dev --host 127.0.0.1 --port 5173
   ```
3. **右邊手機(長輩)**:台北通 App(模擬器或實機),進「服務」→ 熱門 →「陪辦」。語言保持中文。
   登入帳號的**身分證字號要和看護填的長輩身分證字號相同**。官方 App 的示範帳號是 `A123456789`,
   所以示範資料用同一組。
4. **左邊手機(看護)**:瀏覽器開 `http://127.0.0.1:5173/assist/help`(實機要同一個 Wi-Fi,
   後端與 Vite 都要改成 `0.0.0.0`,網址改成電腦的區網 IP)。語言選 **Indonesia**。

## 展示腳本(約 2 分鐘,只投影實機畫面,不用簡報)
| 步驟 | 看護(左,印尼文) | 長輩(右,中文) | 要講的一句話 |
|---|---|---|---|
| 1 | 選「Pengasuh(看護)」,按「Isi data contoh」,勾同意,按「Buat QR」 | (停在「陪辦」首頁) | 「看護不會中文,但她可以用自己的語言幫阿公辦。」 |
| 2 | 畫面顯示「等長輩看到並確認」 | **立刻**跳出紅色「新」徽章與系統通知 | 「按下去,阿公的手機馬上知道。」 |
| 3 | | 按「查看」→「我同意」→ 看一欄一卡的資料(可按喇叭朗讀) | 「大字、一次一個欄位、會念給他聽。」 |
| 4 | | 按「有錯」→ **點**「銀行帳號」→「送出給對方」 | 「不用打字,點一下就好。」 |
| 5 | **立刻**顯示「長輩說有地方不對:銀行帳號不對」(印尼文) | | 「看護馬上用她看得懂的話知道哪裡錯。」 |
| 6 | 改好,按「Buat yang baru」再送出 | 再次跳出邀請 → 同意 → 都對 → 確認送出 | |
| 7 | 變成綠色:「長輩已確認,申請已送出」+ 案號 | 顯示完成與案號,5 秒內可撤回 | 「整個過程,阿公只按了確認。」 |

**備援(後端或網路出問題)**:長輩手機按「掃描 QR」,用「從相片掃描」讀看護產生的 QR;
或不設環境變數,用單機記憶體模式(預設)獨自完整演示。

## 常見問題
- **長輩手機沒收到邀請**:確認兩邊身分證字號相同;確認 App 的「陪辦」頁面是開啟的(通知只在頁面開啟時輪詢)。
- **看護那端顯示「Tidak bisa terhubung ke server」**:後端沒啟動,或兩支手機不在同一個網路。
- 示範資料全為虛構。
